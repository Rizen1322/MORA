# MORA для iPhone — лёгкая нативная версия

Это исходники первого этапа, не готовая IPA и не перенос всех функций ПК. Цель — независимое воспроизведение на iPhone без обязательного сервера. Минимальное целевое устройство — обычный iPhone 12, второе для проверки — обычный iPhone 13; iOS 17 и новее.

## Открыть на Mac

1. Скопировать папку `apps/ios` на Mac (или распаковать `MORA-iOS-starter.zip`).
2. Открыть `MORA.xcodeproj` в Xcode с установленным iOS SDK. Deployment target — iOS 17.
3. Выбрать схему **MORA**, сначала iPhone Simulator, затем свой подключённый iPhone.
4. Для устройства выбрать свой Team в **Signing & Capabilities**. При конфликте идентификатора заменить `ru.mora.ios` на свой уникальный Bundle Identifier.
5. Run. Добавить небольшой MP3/M4A/WAV через `+`, проверить воспроизведение и блокировку экрана.

Для открытия уже подготовленного проекта Node, Python, FFmpeg, yt-dlp и CocoaPods не нужны. Подпись и установка выполняются Xcode на Mac. Команда проверки без подписи из папки iOS:

```sh
sh scripts/check-native-macos.sh
```

В полном репозитории после изменения TypeScript-планировщика:

```sh
npm ci
npm run ios:prepare
npm run ios:check
sh apps/ios/scripts/check-macos.sh
```

`ios:prepare` пересоздаёт Xcode-проект и статический JS-бандл. Настройки персональной подписи после регенерации нужно выбрать снова. Не хранить ключи подписи в исходниках.

## Что уже заложено в коде

- SwiftUI: три вкладки — главная, медиатека, поиск. На главной быстрые переходы в коллекцию/любимое и последние добавленные треки. В медиатеке переключатель «Все треки / Любимое», добавление в любимое свайпом вправо или через меню.
- Визуальная основа — текущая мобильная веб-версия: хвойный фон `#050d0a`, зелёные поверхности, акцент `#4ade9a`, скруглённые квадратные кнопки. Системные шрифты, статичные контуры в карточке вместо постоянно работающего 3D. Декоративных таймеров, WebView и новых зависимостей нет.
- Мини-плеер с позицией, play/pause и Next всегда над вкладками. Полный плеер открывается шторкой: крупная обложка, любимое, перемотка, транспорт и системная громкость. Контент можно прокрутить при большом шрифте и в горизонтальной ориентации.
- Поиск по названию/исполнителю учитывает локаль, регистр и диакритику, игнорирует пробелы по краям. Используется [системный поиск строк Apple](https://developer.apple.com/documentation/swift/stringprotocol/localizedstandardcontains(_:)); это поиск своей коллекции.
- Светлая/тёмная тема, Dynamic Type, VoiceOver-подписи, основные кнопки от 44 pt. Нет тяжёлого постоянно работающего 3D-фона.
- Импорт аудио из Files с копированием в Application Support: файл сначала проверяется, только затем появляется в коллекции. Исходный файл пользователя сохраняется.
- JSON-медиатека с атомарной записью; при повреждении архива существующие данные не перезаписываются.
- AVAudioEngine, play/pause/seek/next/previous, информация и команды экрана блокировки, пауза при отключении наушников, обработка прерываний и сброса медиасервиса.
- Аудио остаётся доступно после блокировки уже разблокированного устройства. Проверка реального поведения нужна на iPhone.
- Уменьшенные обложки с ограниченным кэшем вместо повторного декодирования полных изображений при каждом обновлении позиции.
- Очередь и позиция сохраняются атомарно, не чаще раза в 10 секунд во время игры, а также при pause/seek и уходе в фон. После запуска контекст восстанавливается на паузе; воспроизведение и системный Now Playing запускаются только действием пользователя. Повторы в очереди сохраняются.
- `PlannerBridge.swift`: статический планировщик из общего ядра через Apple JavaScriptCore в очереди utility. Никакого JavaScript в realtime-аудиопотоке.
- `SourceContracts.swift`: раздельные возможности поиска, рекомендаций, офлайна и доступа к PCM для будущих адаптеров.

## Что ещё не перенесено

AutoMix пока **не исполняется** нативным плеером: мост выдаёт планы, но автоматизация двух дек, time-stretch, EQ, limiter и вокальные партии требуют следующего этапа. Нет нативного MIR-анализа, онлайн-поиска, интернет-радио, загрузок по сети, синхронизированных текстов, плейлистов и переноса библиотеки ПК. На главной запускается обычное перемешивание локальной коллекции, без ложной маркировки «AutoMix».

Текущий запас громкости −6 дБ временный; это не перенос измеренной нормализации и ограничителя. Неподдерживаемый Apple декодером формат сообщит об ошибке импорта. Форматы и Bluetooth/AirPlay нужно испытать на устройстве. Иконка приложения и финальная визуальная полировка ещё впереди.

## Что проверено здесь

Генерация проекта и JS-бандла, эквивалентность планов общему ядру, fallback и ручной Next, валидация входа. Среда разработки — Windows: SwiftUI/AVFoundation и настоящий JavaScriptCore здесь **не компилировались и не запускались**. `check-native-macos.sh` предназначен для первой обязательной проверки на Mac, не означает уже пройденную сборку.

Полный план переноса и исследованные ограничения источников — `docs/ios-preparation.md` в основном репозитории.

Нативные тесты входят в Swift Package: `swift test --package-path .`. Скрипт `check-native-macos.sh` выполняет их перед сборкой. Помимо сохранения позиции проверяются поиск (регистр, диакритика, пустая строка и пробелы), чтение прежнего формата трека и отображение времени. Здесь эти Swift-тесты ещё не исполнялись.

## Первая проверка интерфейса на Mac / iPhone

1. Запустить `sh scripts/check-native-macos.sh`, затем приложение на обычных iPhone 12 и 13.
2. В пустой коллекции добавить несколько файлов через Files. Проверить обложки, длинные русские названия и сообщение об ошибке неподдерживаемого файла.
3. Из главной открыть медиатеку и любимое. Смахнуть строку вправо, найти трек по названию и исполнителю, очистить запрос. Повторить поиск с пробелами по краям.
4. Включить трек: мини-плеер должен оставлять видимой последнюю строку списка и вкладки. Раскрыть/свернуть плеер, перемотать, нажать pause/Next/previous; убедиться, что шторка следует за текущим треком.
5. Повторить в светлой/тёмной теме, с самым большим размером текста, VoiceOver и в горизонтальной ориентации. Элементы не должны накладываться; до транспорта можно прокрутить экран.
6. Заблокировать телефон, проверить системные команды и продолжение аудио, затем перезапустить приложение: коллекция и позиция сохраняются, автоматического старта нет.

Визуальная приёмка и замеры памяти/батареи ожидают запуска на Mac/iPhone.
