# MORA 0.3.20: состояние плеера и преждевременный конец трека

24 октября 2026. Исправления в ветке `ios`.

Подтверждены две гонки управляющего состояния: старый paused-tick мог отменить в интерфейсе новую команду Play, а запоздалый underrun переводил пользовательскую паузу в buffering и затем playing. Теперь ticks не заменяют Play/Pause intent, underrun меняет статус только во время воспроизведения. Для меньшей задержки команд запрашивается интерактивный профиль AudioContext; реальная задержка зависит от аудиоустройства.

Второй сбой связан с обрезанным PCM-кэшем при прогрессивной загрузке. Смена WebM на извлечённый Opus несовместима с продолжением чтения по тому же байтовому смещению. Для растущего потока запрещены extraction/fixup. Кроме того, EOF во время публикации не завершает чтение до проверки оставшихся байтов итогового файла.

Прошли 125 тестов в 4 файлах: controller, progressive-audio, public-warmup, engine. Новые сценарии воспроизводили сбои до исправления; для WAV/WebM весь полученный PCM сравнивается с полным декодированием. Типы core/server/web/desktop/ios/mobile прошли.

Установщик и автообновление проверяются verify-release. Тесты не подтверждают исправление отдельной проблемы iOS lock-screen ownership, исследованной ранее.
