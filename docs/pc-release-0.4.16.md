# MORA 0.4.16

Windows x64, Tauri. Обновление доступно через настройки приложения и установщик GitHub Releases.

- Онлайн-волна восстанавливает подбор после «Продолжить», в том числе для старых сохранённых очередей.
- Закрытые и недоступные записи пропускаются. После нескольких ошибок подбор возобновляется с паузой, без повторного выбора тех же записей в текущей сессии.
- Исправлены обрывы воспроизведения и ранние переходы AutoMix при неверной длительности записи.
- Исправлено восстановление приложения после отказа запуска установщика. Обновления скачиваются потоком с проверкой размера и SHA-512.
- Резервные копии поддерживают большие библиотеки и историю свыше 50 000 прослушиваний; предел экспорта и восстановления согласован на 128 МиБ.
- Исправлены клавиатурное управление поиском, выбор повторяющихся песен, повторная отправка форм, сообщения об ошибках и направление сдвига текста песни.
- Исправлено завершение потока событий при перезапуске сервера. CI проверяет Rust-компоненты и сборку Tauri.

Проверки исправлений: 1481 тест прошёл, два пропущены существующими условиями; TypeScript и нативные тесты прошли. Скрытая Tauri-сборка продолжила воспроизведение с трека 0 до 9 при замороженном интерфейсе, восстановила очередь и пережила перезапуск сервера на паузе.

Ограничения: отдельный тест медиакнопок Windows не увидел SMTC-сессию в среде проверки; требуется ручная проверка. Требующие авторизации записи не становятся публичными: волна выбирает другие доступные рекомендации. Установщик не подписан сертификатом Windows.
