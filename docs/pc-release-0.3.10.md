# MORA 0.3.10

Planner `am-planner-v11-dj-6`, analyzer `am-analyzer-11`. Локальная подготовка, без новых моделей, зависимостей и внешнего сервера.

## Новые отрицательные оценки

Проверены сохранённые события установленного профиля:

| Событие | Пара | Старый вход B | Новый вход B | Причина |
| --- | --- | ---: | ---: | --- |
| 256 | Быть богатым → Money | 12,209 с | 2,609 с | Прежний cue внутри фразы 5,6–18,5 с; новый оставляет 2,991 с измеренной подводки |
| 259 | baby my type → Дай мне посмотреть | 5,555 с | 0,4 с | Прежний cue внутри непрерывного голоса; безопасной инструментальной подводки нет, используется начало записи |

Если голос начинается прямо на cue, B открывается за 300 мс вместо мгновенного открытия за 12 мс. При готовых стемах ритмический инструментал A остаётся; при потере PCM сохраняется такой же плавный fallback целой деки. Первые 300 мс входящей фразы при этом приглушены — это компромисс, а не обещание полного уровня первой атаки. Поздние вокальные вступления сохраняют прежнее время gain-rise. Специальный tight phrase-cut остаётся доступным и выбирает только выровненные сильные доли.

Неполный вокальный анализ не считается доказательством инструментальной подводки. Cue вне рассматриваемых вокальных фраз, включая безопасные вступления к сильным частям, сохраняются. Оценки пользователя, база и музыка при диагностике не изменялись.

## Голос готовится заранее

- Focus отправляется ещё до загрузки текущей деки; сервер видит current/next одновременно.
- Один inference-процесс; current 100, next 95, не более двух кандидатов 70. Repeat-one не запускает подготовку посторонних песен, repeat-all учитывает возврат к началу.
- Для кандидатов используются только имеющиеся файлы. Их путь проверяется повторно при старте работы; исчезнувший файл не приводит к скачиванию. Candidate prepare не обходит эту защиту.
- Старые queued задания удаляются при смене фокуса, current/next и ближайшие кандидаты защищены от LRU; устаревшие pins освобождаются через короткий grace.
- Постановка заданий выполняется пакетом, чтобы не загружать Whisper перед следующим отсутствующим вокалом. Кандидаты не запускают распознавание слов.

## Тексты и нагрузка

Пословная подсветка использует реальные сохранённые Whisper-тайминги, без интерполяции по длине строки. Работают смещение, перемотка, подсветка текущего слова, паузы между словами, fullscreen и боковая панель. Готовые локальные слова возвращаются сразу, даже если LRCLIB недоступен; после завершения распознавания открытая панель обновляется отдельным событием. Без готовых таймингов сохраняется построчный текст. В установленном профиле готовых Whisper-текстов не найдено; дополнительный пакет/модель не устанавливались.

Отдельные строки мемоизированы: тики времени обновляют слова текущей строки, а не весь набор слов песни. Сетевой поиск ограничен общим бюджетом 12 секунд. Добавлены предел локального JSON 2 МиБ и защита SSE от неограниченного исходящего буфера; переподключение восстанавливает готовность перехода и текстов.

Подтверждённые и неподтверждённые замечания стороннего аудита разделены в [проверке аудита](audit-followup-2026-10-22.md). Остальные пункты не объявляются исправленными.

## Проверки

Шесть аудиорендеров этих пар: обычная скорость, ×1,2, +3 полутона; отчёт и два обычных WAV находятся в `tools/.cache/automix-review-0.3.10/`. Проверка файлов не запускает звук и не меняет очередь. Субъективное прослушивание не выполнялось.

Тесты проверяют подготовку/удаление кандидатов, файловую гонку, пакетную постановку, отпускание старого focus, приоритет separation перед ASR, уведомление готовых слов, поведение при потере SSE, offline lyrics, сроки запросов, karaoke паузы, безопасные музыкальные cue и PCM fallback.

Итоговые числа тестов, контрольная сумма установщика, запуск и сохранность библиотеки фиксируются после проверки в `release-0.3.10.json`. Изменения iOS ограничены обновлением общего статического planner bundle; Swift на Windows не компилировался.
