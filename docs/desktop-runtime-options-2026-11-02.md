# ПК: следующие шаги после Rust-аудиоядра

Проверено по официальной документации 2 ноября 2026 года. Это оценка дальнейшего переноса; Tauri, reqwest и Symphonia пока не добавлены в приложение.

| Слой | Предлагаемый шаг | Что проверять до переноса |
| --- | --- | --- |
| Оболочка Electron/React | Прототип Tauri 2 с существующим React-интерфейсом и Rust-аудиоядром | Холодный запуск, память всего дерева процессов, CPU открытого/скрытого окна, SMTC, трей, updater, установщик |
| Сеть и локальные сервисы | Постепенно переносить загрузки и кэш в Rust с reqwest/Tokio | Повторное использование соединений, отмена, resume, приоритеты, ограничение памяти, совместимость сервисов и токенов |
| Декодирование | Сохранить FFmpeg базовым; сравнить Rust Symphonia на локальных форматах | MP3/AAC/Opus/FLAC, gapless, seek, progressive input, resampling, CPU/RAM и задержка первого звука |

Tauri использует WebView2 на Windows; это сохраняет web UI. Сама смена оболочки не устраняет нагрузку от React, canvas и анимаций. Node-backend и JS-runtime для yt-dlp придётся временно оставить sidecar-процессом, пока их функции не перенесены: полностью убрать Node одной заменой оболочки нельзя. Более компактная поставка — ожидаемый эффект архитектуры, но численный выигрыш MORA без прототипа не измерен.

Reqwest имеет собственный пул соединений и предполагает переиспользование Client. Это полезная основа Rust-сети, но скорость ответа музыкального сервиса и пропускную способность интернета язык не меняет. Переносить работающие провайдеры целиком без измерений не рекомендую.

FFmpeg уже выполняет декодирование нативно, вне JavaScript. Symphonia — реальный Rust-декодер, но список форматов и feature-флаги нужно проверять для выбранной версии. Язык реализации сам по себе не гарантирует ускорения; особенно важны сетевой progressive input и точные границы/задержки записей. До сравнительного прогона удалять FFmpeg не следует.

Источники: [Tauri WebView](https://v2.tauri.app/reference/webview-versions/), [Tauri architecture](https://v2.tauri.app/concept/architecture/), [reqwest Client](https://docs.rs/reqwest/latest/reqwest/struct.Client.html), [Symphonia](https://github.com/pdeljanov/Symphonia).
