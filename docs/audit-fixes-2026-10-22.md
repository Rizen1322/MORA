## Исправлено, проверено только технически (typecheck и чтение кода)

- **7 (TrackList).** Подписка на scroll теперь пересоздаётся, когда список становится непустым. Сценарий empty → loaded → scroll не автоматизирован: в проекте нет DOM-окружения для тестов, новую зависимость не добавлял. В браузере тоже не проверял: тестовый сервер использует `data-dev` и запустил бы полный переанализ из-за `am-analyzer-12`.
- **13 (QueuePanel).** Узкий селектор через `useShallow`: тик позиции больше не перерисовывает очередь. Видимый диапазон с прокладками сделан по образцу `TrackList`, высота строки измеряется. Глазами не проверено, по той же причине.

## Не сделано или сделано частично

- **14, очередь transport.** Записи очереди в `controller.ts` (зона AutoMix-сессии) не обрезаются. Каждая запись весит около 100 байт, а отрисовку ограничивает п. 13.
- **8, Яндекс-треки.** Hooks реакций по-прежнему делают несколько индексированных запросов на трек. Полных сканов больше нет.
- **2, старые задания.** Задания, сохранённые до этой правки, находят свою запись по позиции. Если их плейлист уже переставлен вручную, первое «Обновить» может привязаться к другой записи.
- **9.** Конвертация не вынесена в worker. Блоки по 1 МиБ с `await` не держат event loop заметное время.
- **6.** `stereo_normalization` по-прежнему создаёт два временных float32-массива размером со всю запись.
- **A–C** не трогал: это зона AutoMix, решения только после прослушивания.
