# MORA 0.4.18

Windows x64, Tauri. Обновление доступно через настройки приложения и установщик GitHub Releases.

- Исправлена ошибка «This operation was aborted» при переключении волны с онлайн-радио на «Мою волну Яндекса». Синхронизация станции, которую страница отправила ещё до переключения, больше не отменяет только что начатый запуск: новый запуск всегда доходит до первого трека, а станцию он задаёт сам после его выбора.
- Онлайн-радио на ПК больше не перезапускает поиск станции на каждом шаге воспроизведения. Раньше при коротком остатке очереди страница заново собирала станцию (до нескольких сетевых подборов в несколько секунд) и повторно синхронизировала её с нативным плеером; теперь станцию на ПК восстанавливает и продолжает сам нативный плеер, а страница этим не занимается.
- «Похожее на этот трек» на ПК теперь действительно остаётся похожим: станция держится за выбранный трек и на последующих пополнениях, а не переходит к общей «Моей волне» после первого же трека. Текущая песня при этом не прерывается.
- Вместо технических английских сообщений рантайма («Failed to fetch», «signal timed out») интерфейс показывает понятный текст: нет связи с локальным сервером или источник не ответил вовремя.
- Ошибка отрисовки интерфейса больше не оставляет пустое окно: показывается экран с причиной и кнопками «Попробовать снова» и «Перезагрузить MORA».
- Локальный API отклоняет некорректные параметры истории и волны вместо чтения всей истории или неверной подстановки значений.
