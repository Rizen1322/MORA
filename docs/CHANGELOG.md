# Изменения

## 0.3.15

- Повторное нажатие «Скачать» больше не возобновляет загрузку после отмены.
- Проверка отмены включает две одновременные команды, позднее событие завершения и явную повторную загрузку.

## 0.3.14

- Автоматическая проверка обновлений MORA через GitHub Releases и ручная проверка в настройках.
- Загрузка по кнопке с прогрессом и отменой, проверка SHA-512 перед готовностью к установке.
- Подтверждённая установка с перезапуском; закрытие в трей и обычный выход не устанавливают обновление.
- Стабильный канал без предварительных версий и понижения версии, сохранение медиатеки и настроек.
- Метаданные `latest.yml` для следующих обновлений.

С 0.3.13 необходимо один раз установить эту версию вручную. Установщик пока без сертификата Windows.

## 0.3.13

Первый публичный выпуск MORA на GitHub для Windows x64.

- Настольный интерфейс с медиатекой, поиском, персональной волной, текстами и панелью звука.
- Двухдековый AutoMix, анализ структуры и ритма, локальная подготовка вокальных партий.
- Автономные FFmpeg, yt-dlp и CPU-комплект вокального разделения в установщике.
- Обновлённая защита вокальной передачи; некоторые длинные фразы всё ещё могут уходить неестественно.
- Исходники desktop-версии, документация и автоматические проверки опубликованы отдельно от мобильной разработки.

Установщик пока не подписан. Обновления самого приложения устанавливаются вручную.
