# Проверка MORA 0.3.16

23 октября 2026 года. Перенесены изменения AutoMix, анализа и сервера из основной рабочей папки (desktop-часть: core, server, web).

- Проверка типов core/server/web/desktop прошла; **879/879 тестов**, 106 файлов.
- Новые регрессии: коллизия хэша при анализе, остановка анализа во время загрузки, отмена загрузки вместе с декодированием, точная длина PCM, бюджет памяти длинных записей, частотная характеристика фильтра, стерео-бас в проверке рендером и в анализе.
- Версия анализатора am-analyzer-14: после обновления анализ медиатеки выполняется заново в фоне.

Сертификата Windows нет. Слуховая оценка новых переходов и установка поверх пользовательской копии этим выпуском не проверялись.

Обновление доступно из настроек начиная с 0.3.14. [Поведение и публикация](AUTO_UPDATE.md).
