# Переходы MORA: разбор Astra и идеи

Агент: GPT-6 Astra, low reasoning. Изменения проверены и перенесены в актуальные исходники после выпуска 0.4.8. В установщик 0.4.8 они **не входят**.

## Что исправлено

В soft echo / drop-swap громкость B раньше поднималась с нуля до 0.8 за 10 мс. Теперь она растёт по синусной кривой за половину доли B, максимум 400 мс, и достигает полной громкости за такт B. Огибающая ограничена длительностью перехода. Ритм входа считается по темпу B.

Автоматический echo теперь сохраняет фактическое слышимое начало B и затакт после начальной тишины. Раньше после тишины длиннее секунды точка входа округлялась вперёд до сильной доли и могла обрезать начало фразы. Для Next сохранён выбор энергичного участка, но смягчена атака. Выход A, его фильтр и эхо-хвост не изменены.

Изменены обе реализации, TypeScript и Rust, и версия планировщика для сброса старых планов. Коммит после переноса: `27a444a`.

## Проверки и ограничения

- 113 тестов: 103 core, 8 local/web, 2 server preview.
- Core TypeScript и Rust debug build прошли.
- Совпали 182 сценария TS/Rust: обычное планирование, finalists, Next, начальная тишина, короткие ограничения, разные темпы. В проверке исключена отсутствующая локальная фикстура `liked-transitions.json`; остальные сценарии выполнены.
- Рендер через настоящий MixerCore на синтетическом PCM: энергия B в первые 20–80 мс составляет менее 30% прежней; после раскрытия громкость совпадает. Нет underrun и нечисловых значений, переход завершается.

Это объективная регрессия на синтетическом звуке, а не подтверждённое прослушивание пользовательских пар. Половина доли — выбранный компромисс, не универсальное правило DJ. Начальная атака B намеренно ослабляется. Модели разделения вокала и новые зависимости не добавлены.

## Обзор существующих типов

| Тип | Назначение и результат |
|---|---|
| Beatmatch / bass swap | Совместимые темпы, обмен басом; не изменён. |
| Filter handoff | Короткое ритмическое сведение с фильтрацией A; не изменён. |
| Local rhythm / tempo bridge | Надёжный локальный ритм или смена темпа в разреженном участке; не изменён. |
| Soft echo / drop-swap | Переход между несводимыми темпами; исправлены атака B и обрезание затакта. |
| Loop roll | Разгон петли до 1/8 и ударный вход B. Быстрые 20 мс сохранены как часть эффекта. |
| Loop wash | Петля и low-pass для спокойного B. Быстрый подъём до 0.6 за 20 мс пока сохранён; нужен отдельный подбор по реальным парам. |
| Legacy echo-tail / planEchoOut | Защищает слова по vocalActivity. Быстрые 20 мс до полной громкости пока сохранены: длинный fade может приглушить первые слова. Следующий кандидат на адаптивную атаку. |
| Phrase cut | Намеренный короткий переход 30–120 мс; не превращён в плавное сведение. |
| Intro drop / instrumental bridge | Используют развитие записи и приход баса; не изменены. |
| Crossfade / fallback | Естественное затухание или ненадёжная сетка; сохранён безопасный запасной вариант. |
| Gapless / skip | Последовательное воспроизведение либо быстрый пропуск; не изменены. |
| Tape-stop / vocal decorators | Уже существуют; часть опирается на вокальные измерения. Не расширены. |

## 15 новых вариантов для дальнейшей реализации

Это предложения, а не уже добавленные типы. Каждый можно выполнить локальными DSP, измерениями энергии, спектра и атак, без разделения источников.

| Вариант | Как звучит и когда применять |
|---|---|
| Echo + затакт | Тихо открыть затакт B под хвостом A, раскрыть на первой сильной доле. Для вступлений перед «раз». |
| Echo с адаптивной атакой | Подобрать fade по RMS и onset: длиннее для плотного удара, короче для мягкого начала. |
| Передача на естественном брейке | Убрать A в его реальной паузе и открыть B без наложения ударных. |
| Однотактное дыхание | Оставить короткую музыкальную разрядку перед B, только если эхо достаточно плотное и пауза не выглядит сбоем. |
| Полутемповая передача | Использовать связь темпов 2:1 без растяжения, передать бас на общей границе. |
| Обмен перкуссией | Сначала верх B, затем бас. Для совместимого рисунка и небольшой плотности середины. |
| Полосовой мост | Кратко сузить A до середины, B раскрыть снизу вверх. Избегать вокально плотных пар. |
| Двухступенчатый bass swap | Сначала ослабить низ A, затем на следующую долю ввести низ B, уменьшая суммарный удар. |
| Короткий dub throw | Один ограниченный эхо-бросок вместо длинного хвоста. Для сухой ритмичной музыки. |
| Замедляющееся эхо | Последние 2–3 повтора увеличивают интервал перед существенно более медленным B. |
| Фильтр к приходу энергии B | B появляется приглушённо, спектр раскрывается к измеренному нарастанию энергии. |
| Петля без ускорения | Повторить последний чистый такт A один раз и передать фразу B, без разгона roll. |
| Вход по затуханию хвоста | Открывать B, когда измеренная энергия хвоста A упала до порога, с ограничением ожидания. |
| Короткий тормоз + тихое начало | Короткий tape-stop только на разреженном участке A, затем мягкое открытие B. |
| Сужение → раскрытие стерео | Кратко сузить A, раскрыть сцену B; небольшой эффект с проверкой совместимости с mono. |

Первыми стоит проверить адаптивный echo, вход с затактом и передачу на естественном брейке: они непосредственно решают проблему неуместного начала B. Для каждого нужны ограничения применимости и сравнение рендеров; просто увеличить число случайных эффектов недостаточно.
