# MORA iOS 1.0.4 (build 5), 24.10.2026

Поверх 1.0.3 ([что было там](ios-release-1.0.3.md)):

- Меньше нагрузки на процессор без изменения звука: быстрые пути микшера, лимитера, кроссовера, эха и дециматора анализа сверяются тестами с прежней реализацией. Замер на Node: одна дека в обычной игре −55 % ЦП, проверка перехода рендером −31 %, анализ трека −16 %. Отчёт: [cpu-optimization.md](cpu-optimization.md).
- Сборка: readable-stream 4; подготовка следующего трека останавливается после 3 пропусков подряд.

Проверены типы всех частей и 948 автотестов. На физическом iPhone, Xcode-компилятором и термозамерами здесь не проверено. Проверить на устройстве то же, что для 1.0.3: Play с экрана блокировки после паузы дольше 3 минут, стык начала трека при игре во время загрузки, подключение Яндекса после обновления.
