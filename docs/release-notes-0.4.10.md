Исправлен залипающий резервный кроссфейд, клавиши можно переназначить, служебные разделы переехали в настройки.

- После ручного пропуска следующий переход больше не остаётся «Резервным кроссфейдом» до конца трека. Если сервер был занят и запрос плана не прошёл, MORA повторяет его через 3 секунды; после завершения анализа трека переход перепланируется сразу.
- Клавиши плеера можно назначить свои: Настройки → Дополнительно → Клавиши. Нажмите на клавишу и затем новую комбинацию (можно с Shift и Alt), Esc — отмена. Занятая клавиша меняется местами, «Сбросить» возвращает стандартные. Клавиши работают в любой раскладке.
- Перемещение трека в очереди (по умолчанию Alt + ↑ / ↓) тоже переназначается. Alt + ← / → остаются за «назад» и «вперёд».
- Загрузки, Источники, История и Диагностика убраны из боковой панели и открываются вкладками вверху настроек.

Установщик без цифровой подписи.
