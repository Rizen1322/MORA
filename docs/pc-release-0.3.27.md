# MORA 0.3.27 — проверка радио и полного плеера

Исправлен владелец асинхронного запуска CatalogPlayer: queueVersion запоминается сразу после вызова playTracks, а после подтверждения проверяется заново. Старая радиоподготовка не присоединяет рекомендации к плейлисту, который пользователь запустил во время ожидания. WavePage определяет активный источник по контексту текущей очереди; сессия подбора отключается при другом контексте. Регрессия проверяется отложенным подтверждением транспорта и отдельным тестом повторного запуска радио.

Персональное радио получает свежую серверную историю (до 200 записей) и исключает недавние песни за два часа по нормализованным названию и исполнителю. ID последнего прослушивания участвует в ротации seed; связанные кандидаты переставляются перед ранжированием. Любимые seed больше не добавляются в начало как обязательные песни. В сбалансированном режиме знакомые песни получают штраф в первом слоте и после двух знакомых в первых пяти, при этом при отсутствии альтернатив станция не опустошается. Явный запуск радио по треку по-прежнему начинает с этого трека.

Длина названия влияет на размер шрифта полного плеера только на ПК: свыше 45 и 60 символов используются две более компактные ступени. Текст не обрезается; мобильные размеры не изменены.

Взяты свежие параллельные файлы TS/Rust планировщика v19.3 и его тесты. Маркер кэша automatic plans: transition-styles-4-echo-breathing; PLANNER_VERSION не изменён ради ID одобренных планов. Личные фикстуры не публикуются.

Проверки: 1190 тестов в 153 файлах, TypeScript всех workspace, 266 общих сравнений Rust/TS и 110 проверок новых вариантов планировщика — прошли. Агент нашёл гонку запуска каталога; после исправления повторная проверка замечаний не выявила.

Готовое приложение: Pause/Resume, быстрые Next/Previous, frozen UI 30 с (индекс 1 → 3), восстановление дочернего процесса, очередь/подготовка плейлиста/меню и переход плейлист → страница онлайн-радио прошли. PCM underrun = 0, device underrun = 0; в 79 audioHealth-отчётах был один slowBlock без пропуска устройства. Финальная дополнительная UI-проверка после выбора меньшей ступени шрифта: название 78 символов, 32 px, 4 строки при 1280 px; снимки при 1280 и 960 px просмотрены.
