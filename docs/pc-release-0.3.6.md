# MORA 0.3.6

22 октября 2026. Изменения локальные, без новых зависимостей и внешнего сервера обработки.

## YouTube и YouTube Music в приложении

- YouTube Music использует `net.fetch` Electron в utility process вместо Node fetch. Chromium учитывает системные настройки сети, включая прокси: [официальное описание Electron net](https://www.electronjs.org/docs/latest/api/net). Веб-версия MORA сохраняет обычный серверный transport.
- Перед запуском backend desktop определяет системный маршрут YouTube и SoundCloud через [session.resolveProxy](https://www.electronjs.org/docs/latest/api/session). Каждый источник получает собственный `--proxy` в yt-dlp; DIRECT не заменяется более поздним прокси в PAC-списке. Адреса проверяются, в журнал не записываются. Разрешение маршрутов ограничено тремя секундами и повторяется при перезапуске backend. [Сетевые опции yt-dlp](https://github.com/yt-dlp/yt-dlp#network-options).
- Ошибки `/next` больше не блокируют `/search`: отдельные circuit breakers, восстановление через 15 секунд вместо общей блокировки на две минуты. Уже отменённый запрос не запускается.
- Дочерний процесс загрузчика не наследует ключ шифрования провайдеров MORA.

Это не воспроизводит профиль браузера пользователя: расширения VPN/прокси, авторизация, cookies, браузерный HTTP/3 и антибот-проверки могут отличаться. Настройки прокси с авторизацией и сложные PAC-маршруты CDN требуют отдельной проверки. TLS-проверка не отключается, cookies браузера не извлекаются.

## Анимации

Для нового профиля desktop полный режим включён по умолчанию. Сохранённые пользовательские `system` / `reduced` не переписываются. Для браузерного запуска по умолчанию остаётся системный режим. Явно выбранный полный режим теперь учитывается и CSS, который прежде мог отключать анимации независимо от настроек MORA. Явный минимум движения уменьшает CSS-анимации и без системной настройки. Существующие ограничения FPS/DPR, остановка скрытых сцен и совместимый Canvas сохранены.

## AutoMix

Planner `am-planner-v11-dj-3`, статический iOS JS bundle обновлён для соответствия общему ядру; Swift на Windows не компилировался.

- При готовности только вокального анализа B фейдер и EQ B завершают открытие к фактическому уходу A. Поздний bass swap не возвращает искусственный провал баса.
- Pre-fader echo A удаляется в этом режиме: неизвестный старый голос не возвращается после ухода сухого сигнала.
- Проверка вокала B охватывает весь участок DJ-фильтрации до возврата фильтра в нейтраль, включая затакт.

Разбор, реальные пары и следующие техники: [отчёт агента](automix-agent-review.md). Девять объективных рендеров: 0 underruns, максимальный true peak −2,710 дБ. Эти измерения не заменяют прослушивание.
