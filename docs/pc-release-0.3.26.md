# MORA 0.3.26 — завершение подключения планировщика

Сверка с опубликованной 0.3.25 показала: 39 файлов алгоритма TypeScript/Rust совпадают, включая v19.2. Не были перенесены три файла подключения: apps/server/src/automix.ts, apps/server/src/routes/playback.ts, apps/desktop/src/desktop-playback.ts. В 0.3.26 перенесены catchUp после пропущенной точки сведения, новый ключ кэша transition-styles-3-wash-next и обновлённое окно замены резерва.

При независимой проверке агентом найдено несовпадение порогов: реальный requested-кроссфейд начинается через 80 мс от запрошенной позиции, но плеер принимал план только при запасе более 300 мс. Для автоматического catchUp запрашивается позиция на секунду впереди; остаются проверки актуальности пары и запаса перед постановкой плана. При слишком медленном расчёте подготовленный резерв сохраняется.

Добавлены два регрессионных теста: настоящая цепочка DesktopPlayback → planRequestedTransition → native arm для пропущенной точки и API catchUp при mixOnNext=false с сохранением настройки. Личные фикстуры не публикуются.

Проверки: 1186 тестов в 153 файлах прошли, TypeScript всех workspace прошёл. Целевые тесты API и DesktopPlayback: 23 прошли. Алгоритм TypeScript/Rust не менялся относительно 0.3.25; предыдущая проверка паритета 266 + 110 сравнений остаётся применима.

Установщик MORA-Setup-0.3.26.exe: 170255067 байт, SHA-256 `4d58b14bf07bc0dbc60d143ef2c641e25185a18442739ea4998a3a2d9f675f5d`. verify-release проверил манифест, blockmap, bundled host и нативные бинарные файлы.

Упакованная 0.3.26 прошла реальный WASAPI-прогон: Pause/Resume, Next/Previous сериями, переключение выхода, очередь при frozen UI 30 секунд (индекс 1 → 3), восстановление после остановки дочернего аудиопроцесса. 70 audioHealth-отчётов: 0 PCM underrun, 0 device underrun, 0 slowBlocks. Также прошли подготовка плейлиста, отмена удаления из очереди и проверки меню/плеера. Артефакты: data-bench-results/desktop-0.3.26/.

Проверялось с нулевой громкостью на синтетических WAV; длительное прослушивание реальной музыки не проводилось. Установщик без Authenticode.
