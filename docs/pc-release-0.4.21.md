# MORA 0.4.21

Windows x64, Tauri. Обновление доступно через настройки приложения и установщик GitHub Releases.

- Убран стартовый мини-экран «Запуск локального сервиса…». Приложение больше не показывает отдельное окно перед запуском: сразу открывается настоящее окно MORA, как только локальный сервис готов. Если сервис не удалось запустить, вместо этого появится диалог с причиной и кнопками «Повторить» и «Выйти».
