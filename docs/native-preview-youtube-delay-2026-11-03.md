# Native Preview 0.3.32: задержка подготовки онлайн-перехода

Проверка профиля 0.3.31 только для чтения показала: около 50 секунд ожидания remote-файла, затем примерно 1–2 секунды анализа. Задержка была в получении звука, а не в музыкальном выборе перехода.

Контролируемое сравнение на одной записи YouTube длиной 98.841 секунды (WebM, 1 679 348 байт):

| Путь | Полная загрузка | Первые байты |
| --- | ---: | ---: |
| Native Preview 0.3.31: Rust передаёт файл | 51.698 с | 2.819 с |
| Прежний транспорт yt-dlp | 1.760 с | 1.616 с |
| Исправленный путь, Rust helper остаётся включён | 2.048 с | 1.835 с |

В исправленном варианте YouTube использует существующий транспорт yt-dlp с исходным контейнером; Rust-загрузка этого файла не вызывается. SHA-256 результата совпал с записью, полученной предыдущим вариантом. Метаданные, другие провайдеры и нативное декодирование сохраняют прежние пути. Отдельный native downloader SoundCloud продолжает работать.

Причина различия поведения CDN для двух HTTP-клиентов не установлена. Поэтому добавлен точечный отказ от экспериментального транспорта для YouTube, а не изменение числа параллельных загрузок или предположение о размере HTTP-чанков. Размер этого файла меньше 2 МБ.

Дополнительно исправлено сохранение состояния анализа при замене временного remote-хеша реальным: завершившаяся задача больше не оставляет прежнюю запись running. Это отдельная ошибка диагностики, не причина 50-секундной загрузки.

Прошли 13 регрессионных проверок маршрутизации загрузки, прогрессивного PCM и отмены анализа, ещё 18 проверок прогрева, очереди загрузчика, отмены передачи и жизненного цикла анализа, а также TypeScript сервера. Проверка YouTube закрепляет сохранение приоритета, отмены и исходного контейнера, без повторного кодирования и без нативной передачи байтов. Из финального NSIS извлечены EXE и ресурсы: исправленный backend проверен, скрытый запуск и нативное воспроизведение с продвижением позиции прошли на временном профиле.

Локальный установщик: `MORA-Native-Preview-0.3.32-preview.1-Setup.exe`, 96 132 271 байт, SHA-256 `07ad140635d9d2be0396b816b61ba857253b7d3e5520464d081f86aa557f5064`. Сохраняет отдельный профиль Native Preview; не опубликован.

Сырые обезличенные результаты: `native-preview-youtube-delay-2026-11-03.json`. По одному живому прогону на путь; это не гарантия скорости для всех треков, источников или сетей. Профиль пользователя не изменялся, музыка не воспроизводилась, тестовые файлы удалены.
