# MORA 0.3.19 для Windows x64

24 октября 2026. Режим «Минимум движения» получил статичную композицию из тонких мятных линий вместо запасного круга на главной и в «Моей волне». В полноэкранном плеере этот режим использует фон в цветах обложки без запуска Canvas/WebGL-рендерера.

Настройка: Оформление → Анимации → Минимум движения. Проверены внешний вид на широком и узком экране и сохранение полного визуализатора при выборе полных анимаций. Сборка содержит AutoMix без локального вокального runtime.

Версия desktop-пакета, package-lock и автообновления согласованы на 0.3.19. Установщик NSIS и файлы автообновления проходят verify-release; отчёт о проверках указан в GitHub Release.

Релиз: [v0.3.19](https://github.com/Rizen1322/MORA/releases/tag/v0.3.19). С 0.3.14 обновление доступно через настройки. Установщик пока без сертификата Windows.
