# Независимые скорость и высота тона в MORA 0.3.0

21 октября 2026. Реализовано в `packages/core/src/dsp/playback.ts`, подключено к MixerCore и панели «Звук». Это замена первоначальному плану с преобразованием каждого источника отдельно.

## Общий таймлайн

Деки и их beatmatch-WSOLA работают в музыкальном времени. Точки входа/выхода, vocal masks, EQ, swap, gap и echo исполняются вместе. Готовый микс проходит цепь:

`WSOLA (speed / pitch) → sinc-ресэмплер (pitch) → реверберация → тон/баланс/моно → громкость → true-peak limiter`.

`pitch = 2^(semitones/12)`. Потребление исходного времени соответствует speed, спектральный сдвиг — pitch. Автоматизацию каждой деки не нужно независимо перестраивать при движении регулятора. Голос вычитается до этого этапа, вокальный echo проходит ту же обработку.

Два кольцевых буфера обеспечивают чтение назад для WSOLA; память зависит от sample rate, а не длины песни. FIR: 64 отсчёта, Blackman-окно, low-pass против алиасинга при повышении тона. Тригонометрия вынесена в таблицы. До включения эффект обходится точно. После возврата к нейтрали буферный путь сохраняется до запуска/перемотки/остановки, чтобы не пропускать накопленное окно.

Регулировки сглажены за ~40 мс. Первое включение подмешивает исходное окно на 30 мс, компенсируя стартовую Hann-огибающую WSOLA. Есть дополнительное опережение в десятки миллисекунд: телеметрия компенсирует буфер, окончание записи дожидается его выхода. Это не режим сверхнизкой задержки для живого инструмента.

## Настройки и поведение

- Скорость 0,8–1,2×, шаг 0,01; тон −6…+6 полутонов, шаг 0,5.
- Двойной щелчок сбрасывает регулятор; общая кнопка — оба.
- `sound.playback` хранится отдельно от EQ; старый профиль получает 1×/0.
- Seek, ручной запуск и Stop очищают буферы; пауза замораживает их после штатного затухания.
- Записи настроек сериализованы: устаревший HTTP-ответ не откатывает новые регуляторы. Media Session получает скорость.
- Офлайн-рендер использует тот же MixerCore и принимает PlaybackSettings.

## Проверки

`playback.test.ts`: точный neutral bypass, независимые частота/длительность на краях диапазона, антиалиасинг на 22 кГц, непрерывная регулировка, общий тайминг перехода с gap, true peak, seek/stop, дренирование перед ended. `sound-settings.test.ts`: гонки сохранения.

`tools/check-playback-release.ts` сохранил девять WAV на трёх реальных парах в `tools/.cache/automix-review-0.3.0`: без underruns, NaN и превышения потолка. При 1,2× 19 с превращаются в 15,833 с; при +3 полутона остаются 19 с.

Повторный замер двух одновременно растягиваемых дек на этой машине: median 0,060 мс, p95 0,508 мс, p99 0,785 мс, max 1,522 мс при бюджете 2,667 мс/128 отсчётов. Первый прогон имел max 1,587 мс. Это отдельные прогоны, не гарантия при любой фоновой нагрузке.

Форманты при смене тона не сохраняются. На крайних значениях возможны артефакты WSOLA. Агент звук на слух не оценивал; примеры предназначены для прослушивания пользователем.

Основа ресэмплера: [Julius O. Smith — Windowed Sinc Interpolation](https://www.dsprelated.com/freebooks/pasp/Windowed_Sinc_Interpolation.html). Реализация собственная, второго плеера нет.
