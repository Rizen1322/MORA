# Проверка MORA 0.3.17

24 октября 2026 года. Перенесены изменения core, server и web из основной рабочей папки.

- Проверка типов core/server/web/desktop прошла; **948/948 тестов** в основной папке.
- Пять оптимизаций ЦП (микшер, лимитер, кроссовер, эхо, дециматор анализа) сверяются тестами с прежней реализацией: звук не меняется. Замер на Node: одна дека в обычной игре −55 % ЦП, проверка перехода рендером −31 %, анализ трека −16 %.
- Вокальная модель (CPython, PyTorch, Demucs) больше не входит в установщик; проверка собранного backend требует, чтобы модель была недоступна, а AutoMix работал без неё.
- Новые регрессии: прослушивание перехода (WAV из того же микшера), чтение растущего файла после переноса в кэш, сон звукового движка на долгой паузе, тики движка и перерисовки при свёрнутом окне, автопродолжение радио, учёт оценок переходов, анализ медиатеки только в простое.

Сертификата Windows нет. Слуховая оценка и установка поверх пользовательской копии этим выпуском не проверялись.

Обновление доступно из настроек начиная с 0.3.14. [Поведение и публикация](AUTO_UPDATE.md).
