# MORA 0.1.2 — обновление компонента источников

21 октября 2026. Добавлено обновление yt-dlp из настроек настольной версии. Браузерная версия такой возможности не предоставляет.

## Поведение

- Проверка выполняется по нажатию пользователя, без фонового скачивания исполняемых файлов. Используется официальный stable-релиз `yt-dlp/yt-dlp` через GitHub API.
- При установке метаданные перечитываются. Допустим только фиксированный адрес официального `yt-dlp.exe` и `SHA2-256SUMS` для проверенного номера версии.
- Скачивание ограничено по времени и размеру. Проверяются SHA-256 и заголовок Windows EXE. Затем файл запускается только с `--version` с ограничением времени; ответ должен совпасть с номером релиза.
- До завершения проверки рабочий выбор не меняется. Новая версия сохраняется отдельно в профиле MORA, комплект приложения не перезаписывается. Указатель версии публикуется через временный файл и переименование.
- Обновление не перезапускает сервер и не прерывает музыку. Выбранная версия используется при следующем запуске приложения.
- Кнопка отката выбирает предыдущую проверенную версию или встроенную. При повреждении выбранного EXE приложение автоматически использует встроенный. Это проверка целостности и запуска, а не гарантия совместимости каждой записи; при регрессии источников нужен ручной откат.
- Renderer не передаёт адреса, пути или команды: доступны только четыре фиксированных IPC-операции с существующей проверкой доверенного окна.

## Проверка

- Четыре новых теста: установка и откат; неверная сумма и неработающий EXE; посторонний адрес и повреждение установленного файла; параллельные операции. Все прошли.
- Проверка типов всех пакетов и проверка синтаксиса main/preload/updater прошли.
- Реальное обращение к GitHub, скачивание официального EXE в изолированную папку `tools/.cache/updater-live-smoke`, проверка суммы, запуск и откат прошли. GitHub на момент проверки сообщил stable `2026.08.19`, совпадающий с комплектной версией. Интерфейс учитывает номер встроенной версии и не предлагает повторное обновление до неё.
- Реальная проверка выявила HTTP 415 при неподходящем Accept для GitHub API; заголовок исправлен, в тест добавлена соответствующая проверка.
- Собран `apps/desktop/dist/MORA-Setup-0.1.2.exe`. Производственная web-сборка также включена в установщик.
- Полный предыдущий прогон 555 тестов относится к 0.1.1; на этом шаге выполнялись новые тесты и проверка типов. Автоматизированная проверка кнопок в настоящем окне Electron не выполнялась. Пользовательский установленный профиль не обновлялся и его версия yt-dlp не менялась.

Исходные данные: https://github.com/yt-dlp/yt-dlp#update и https://api.github.com/repos/yt-dlp/yt-dlp/releases/latest . Контрольная сумма получена через HTTPS с того же официального релиза; отдельная криптографическая проверка подписи релиза не реализована.

Следующие отдельные задачи: progressive start с сохранением полноценного анализа AutoMix; Discord Rich Presence; независимая скорость/высота тона, реверберация и перевод текстов. Детали предыдущих исправлений — `mora-audit-0.1.1.md`.
