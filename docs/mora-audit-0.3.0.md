# MORA 0.3.0 — темп/тон и автономный вокальный компонент

21 октября 2026. Перевод текстов, Discord и iPhone исключены по указанию пользователя.

## Готово

- Независимые скорость 0,8–1,2× и тон ±6 полутонов в «Звуке», сохранение и сброс. AutoMix, голос и автоматизация проходят общий музыкальный таймлайн. Ограничитель остаётся последним. [Устройство и проверки](playback-speed-pitch.md).
- Плавная регулировка посреди песни. Исправлены откат настроек устаревшим ответом сервера и преждевременное окончание при ещё не вышедшем буфере обработки.
- Разделение вокала для YouTube/SoundCloud через прежние PCM/кэш. При смене проверенного хеша записи задание переходит на новый хеш; чужие партии под старым ключом не публикуются. Политика запрещённых источников сохраняется.
- В настольную сборку включены Python, CPU-зависимости и HDEMUCS_HIGH_MUSDB_PLUS. На машине слушателя не нужны Python, CUDA, pip и скачивание модели. Внешний Python можно настроить отдельно. Статус показывает встроенный CPU-комплект.
- Возможности 0.2.0 сохранены: полный импорт лайков, ранний старт, текст в полном плеере, анимации и реверберация.

## Автономный комплект

`node apps/desktop/scripts/fetch-vocals.mjs --python <Python 3.12 машины сборки>` создаёт `apps/desktop/vendor/vocal`. Wheels устанавливаются в отдельный target, системные пакеты не меняются. Версии закреплены, архив Python и модель проверяются по SHA-256. Изолированный `_pth` не использует пользовательские Python-модули. Лицензии и `pack.json` сохраняются в приложении. Если комплект отсутствует, сборка прекращается.

CPython 3.12.10, PyTorch/Torchaudio 2.7.1+cpu, NumPy 2.2.6. Модель 334 697 255 байт, SHA-256 `a004b2790d73ffeaa535db458a1a79b539dfdbafbccc31f275d07e632ebd7816`.

Прямая проверка `dist/win-unpacked/resources/vocal/python.exe` с комплектным скриптом: PATH только Windows/System32; двухсекундный WAV → 88 200 отсчётов на канал, `vocal-activity-2`, CPU, 3,77 с внутри скрипта. Это проверка исполнения, а не качества отделения голоса по синусу. Длинные записи готовятся дольше; до готовности партии доступны остальные переходы.

## Проверки

- Итог: **594/594 теста, 47 файлов, 56,92 с**; проверка типов, production web build и установщик прошли. Финальный установщик: **480 297 187 байт**, 21.10.2026 13:50:55 (Москва).
- Браузер, отдельная синтезированная медиатека: 1,2×/+0,5 полутона, пауза/продолжение, сохранение после перезагрузки, ошибок консоли нет. [Скриншот](screenshots/desktop/sound-playback-0.3.0.png).
- Backend из ресурсов внутри Electron 44.9.2, чистый PATH: `bundled-cpu`, миграция 1×/0, поиск 441 мс, создание записи 38 мс, первые 65 536 байт PCM за 2,501 с от подготовки, JPEG 56 107 байт, полный импорт лайков HTTP 200. Это не задержка до колонок и не проверка нативного окна.
- Изолированная копия тестового профиля 0.2.0 открыта новой версией. Кэшированный YouTube-трек отдал 65 536 байт корректного PCM с отсутствующим yt-dlp и запрещённым fetch: сетевых попыток 0. Пользовательский профиль только читался для выбора уже имеющегося файла. Отчёт: `tools/.cache/offline-upgrade-0.3.0-*/report.json`.
- Три реальные пары: SPACE X → Не бесконечно (87,34→120 BPM), Вверх-вниз → нарисована (72→130), Я в норме → Картинки из снов (136,01→145). Девять рендеров: 0 underruns, конечные отсчёты, true peak от −3,59 до −2,02 дБ, лимитер в этих примерах уровень не снижал. Две пары выбрали фильтрованный crossfade по низкой уверенности сетки, третья — beatmatch. Принудительное сведение по ненадёжной сетке не выдавалось за корректное.
- Аудио и метрики находятся в `tools/.cache/automix-review-0.3.0`, никуда не отправлялись. [Памятка для прослушивания](../tools/.cache/automix-review-0.3.0/README.md). Агент звук на слух не оценивал.
- Повторный замер окончательной логики: median 0,060 мс, p95 0,508 мс, p99 0,785 мс, max 1,522 мс на 128 отсчётов при бюджете 2,667 мс. Прежний отдельный прогон (max 1,587 мс) также укладывался; это не гарантия для любой нагрузки.

## Границы результата

Смена тона не сохраняет форманты. Естественность вокала и сведения нужно оценить по образцам на слух. CPU-комплект увеличивает установщик примерно до 480 МБ; MelBand, Whisper и CUDA в него не входят. Внешние расширения не удаляются. M4A/MP4 всё ещё ждут окончания загрузки; ранний старт работает с последовательными контейнерами. SoundCloud ищется через yt-dlp.

Установленное приложение автоматически не заменялось. Сервер — 4730, установщик — `apps/desktop/dist/MORA-Setup-0.3.0.exe`.
