# MORA 0.4.9 — локальные переходы после прослушивания

Выпуск включает 11 оставшихся рецептов. Однотактное дыхание, полосовой мост, повтор такта и раскрытие стерео удалены вместе с обслуживавшим только стереорецепт кодом.

Рецепты ранее вызывались только инструментами прослушивания. Теперь desktop AutoMix рассматривает их после обычного планировщика, в том числе при предварительной подготовке и проверке PCM. Выбор воспроизводим для пары записей; треть пар сохраняет обычный подбор, остальные выбирают среди подходящих рецептов. При отсутствии пригодного рецепта остаётся обычный план. Сохранённые одобренные переходы разрешаются раньше автоматического кэша; новые рецепты не заменяют альбомные стыки, режим сохранения вступления, плавный стиль, отключённую обработку и неподдерживаемые источники. Оценки пользователя могут исключить неподходящий рецепт. Подбор включён на desktop, остальные платформы сохраняют свой обычный планировщик.

Исправлены две ошибки: EQ-автоматизация при выключенном EQ и округление точки затухания A назад в громкий фрагмент. Звук одобренных примеров тормоза, перкуссии и двухступенчатого баса не изменён. Два варианта каждой из 11 техник повторно отрендерены на тех же исходных записях; новая галерея `data-bench-results/creative-transitions-v4-2026-11-05` находится только в локальной рабочей папке пользователя.

Торможение теперь измеряется при технической проверке PCM; абсолютные времена эффекта сдвигаются на начало загруженного окна в обеих реализациях. Обычное сведение другой длины остаётся допустимым запасным вариантом после рендера. Сгенерированный рецепт помечается непроверенным до получения PCM, поэтому его предварительное кэширование не отключает последующую проверку.

Проверки: 945 тестов в 125 файлах, TypeScript всех приложений, сборки Rust и Tauri release. 231 сравнение планов TS/Rust прошло как с debug, так и с выпускным аудиоядром. Все 22 реальных плана сверены между реализациями; для каждого из 11 стилей PCM одной реальной пары совпал побайтно. WAV шести ранее одобренных примеров совпали с v3 по SHA-256. Скрытый Tauri release прошёл проверку окна, desktop bridge, состояния без воспроизведения, восстановления backend и ограничения второго экземпляра в отдельном профиле.

Расширенный первый прогон выявил устаревшую заглушку `pcm.status` и таймаут импорта с debug-аудиоядром. Заглушка дополнена; полный итоговый прогон выполнен с release-аудиоядром и прошёл. Код приложения ради таймаута не менялся.

Обработка локальная, модели разделения источников не используются. Исходные треки, личная медиатека и учётные данные не включаются в выпуск. Длительное субъективное прослушивание ассистентом и установка поверх пользовательского профиля не проводились. Установщик не подписан Authenticode.
