MORA для iPhone

Прототип редизайна. Мышь работает как палец: тяните, свайпайте, удерживайте.

  1. Тап по треку — играет; появляется мини-плеер.
  2. Скролл вниз — панель вкладок сжимается, мини-плеер встаёт в её строку.
  3. Тап по мини-плееру — обложка «перелетает» в полный плеер.
  4. Тяните плеер вниз за обложку или «ручку» — закрывается с учётом скорости.
  5. Свайп строки влево — «В очередь», вправо — «Играть следующим». Длинный свайп срабатывает сразу.
  6. Долгое нажатие / правый клик — контекстное меню.
  7. Текст и Очередь внизу плеера — обложка уезжает в шапку.
  8. Аватар на Главной — шит с двумя высотами (вместо вкладки «Ещё»).
  9. Повторный тап по вкладке — наверх.
