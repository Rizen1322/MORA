# MORA для Windows

## Первый запуск

Скачайте установщик из [Releases](https://github.com/Rizen1322/MORA/releases/latest), установите приложение и откройте MORA. Системные Node.js, Python и FFmpeg для готовой сборки не нужны.

Добавьте файлы или папку через импорт. Приложение прочитает метаданные и обложки и подготовит анализ в фоне. Для онлайн-источников используйте поиск. Доступность записей зависит от сервиса и региона; внешний сервис может менять правила и способы доступа.

## AutoMix

AutoMix подготавливает следующую пару и выбирает переход с учётом доступного анализа. Для сведения по битам необходим достаточно уверенный ритм. Голос остаётся частью общей записи: отдельная модель вокала с 0.3.17 не используется.

Если переход звучит неудачно, сохраните оценку и укажите пару треков, место и характер проблемы: обрыв строки, конфликт ритма, басовая яма или резкий скачок. Одинаковый BPM сам по себе не гарантирует хорошего сведения.

## Звук и тексты

В панели звука доступны эквалайзер, пресеты, баланс и другие настройки. Большой подъём полос может потребовать запаса по уровню. Настройки скорости и высоты тона независимы.

Текст открывается в плеере. Наличие и точность синхронизации зависят от источника текста; распознавание всех слов каждой записи в установщике не обещается.

## Где хранятся данные

Профиль находится в `%LOCALAPPDATA%\MORA`, медиатека — в подпапке `data`. Для резервной копии всей медиатеки закройте приложение и скопируйте папку целиком. Экспорт плейлистов не является резервной копией аудиофайлов, кэша и подключённых аккаунтов.

Токены подключённых сервисов вводятся в приложении. Не прикладывайте их, файлы профиля или полные базы к публичным Issues. Перед отправкой логов удалите личные данные и секреты.

## Обновление

Начиная с 0.3.14 MORA проверяет новые версии автоматически. В «Настройки → Приложение → Обновление MORA» можно запустить проверку вручную, скачать обновление или отменить загрузку. Музыка продолжает играть во время загрузки. После проверки файла появится кнопка «Установить и перезапустить»; программа попросит подтвердить остановку музыки и перезапуск. Обычный выход или закрытие в трей установку не запускают.

С версии 0.3.13 нужно один раз установить последнюю версию вручную из Releases: в старой программе ещё нет обновлятора. Медиатека и настройки хранятся отдельно от приложения; перед обновлением разумно иметь их резервную копию.

Обновление встроенного yt-dlp в настройках — отдельная функция; оно не обновляет само приложение.

## Известные ограничения

- Установщик пока не подписан сертификатом Windows.
- Сетевые источники экспериментальные; их доступность может меняться независимо от MORA.
- AutoMix не гарантирует естественный конец каждой вокальной строки и идеальный переход для любой пары.
- Воспроизведение импортированной/загруженной музыки возможно без сети; поиск и получение новых онлайн-записей требуют подключения.
