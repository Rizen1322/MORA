# MORA 0.4.17

Windows x64, Tauri. Обновление доступно через настройки приложения и установщик GitHub Releases.

- В контекстном меню трека (ПКМ) на верхний уровень возвращён пункт «Заменить трек» для выбора другой версии записи без изменения обложки, названия, лайков и плейлистов.
- Исправлено редкое залипание «Резервного кроссфейда» на ПК при фоновом обновлении очереди (подгрузка следующих треков онлайн-радио или применение дизлайков), из-за которого реальный план перехода не применялся до ручной перемотки.
