# MORA 0.2.0 — полный импорт, ранний старт и полный плеер

21 октября 2026. Продолжение проверки после 0.1.3. iPhone в эту работу не входит.

## Что изменилось

### Полный плеер

- Перестроение заголовка между разным числом строк анимируется через FLIP и ResizeObserver. Уходящий заголовок больше не удерживает высоту сетки до конца своей анимации. Повторная смена трека учитывает незавершённое движение. При reduced motion движение отключено.
- Кнопка текста переключает обложку на встроенный текст песни. Тёмная подложка сохраняет контраст на ярком фоне, текущая строка выделяется. Клик перематывает, ручная прокрутка временно отключает слежение, кнопка возвращает к текущей строке. Сдвиг тайминга сохраняется для записи.
- Проверены загрузка, отсутствие текста, ошибка, возврат к обложке и смена записи. Старый ответ не подменяет текст новой записи.
- Исправлен Next на паузе: следующий трек выбирается и остаётся на паузе. Раньше переход ожидал остановленные аудиочасы. Исправлена гонка ручного запуска с фоновой подготовкой на ту же деку.

Скриншоты: [1280×820](screenshots/desktop/lyrics-stage-0.2.0.png), [960×680](screenshots/desktop/lyrics-stage-960.png). Использован отдельный профиль, синтезированный звук и собственные тестовые строки. Проверены длинный заголовок в три строки и короткий в одну, перемотка по строке, управление на паузе и возврат к обложке. Это проверка в браузере, не полная проверка окна установленного Electron.

### Все лайки Яндекса

Новая команда в «Источниках» читает полный снимок идентификаторов лайков и создаёт сохраняемое задание. Прежние ограничения 60/300 относятся к превью, новое задание их не использует. Защитный предел 50 000 сообщает ошибку, а не обрезает коллекцию молча.

- Два параллельных импорта, прогресс по позициям, пауза, продолжение после перезапуска, повтор ошибок и завершение задания. При трёх ошибках подряд задание приостанавливается.
- Новые лайки остаются сверху независимо от порядка завершения скачиваний. Уже известные записи не скачиваются заново.
- Проверяется аккаунт; продолжение задания другого аккаунта запрещено. Можно завершить старое задание и начать новое. Уже добавленная музыка сохраняется.
- Локальное снятие лайка или дизлайк во время задания не перезаписывается. Массовый импорт не отправляет обратные реакции Яндексу.
- Закрытие страницы не останавливает серверное задание. После перезапуска требуется нажать продолжение.

Проверка на фикстуре 401 записи, обратном порядке метаданных, перезапуске, сетевых ошибках, смене аккаунта и отмене. На реальном аккаунте массовое скачивание всей коллекции не запускалось ради проверки интерфейса.

### Воспроизведение до завершения скачивания

После результата поиска с известной длительностью сервер может сразу создать техническую запись и подать растущий файл в FFmpeg через stdin. PCM поступает в прежний AudioWorklet/AutoMix. Второго проигрывателя нет.

- Раннее чтение разрешено для WebM, MP3, Opus, Ogg, FLAC и WAV. M4A/MP4 ждут окончания: индекс контейнера может находиться в конце файла. Для неизвестной серверу записи остаётся обычная полная подготовка.
- Один сетевой transfer обслуживает параллельные запросы. Поток ждёт новые байты, а не считает временный конец файла окончанием трека. Ошибка скачивания остаётся ошибкой.
- Проверка ffprobe и контрольной суммы обязательна перед публикацией готового файла. Частичный файл не становится загрузкой для офлайна.
- После получения реального хеша сохраняется ключ уже работающего PCM-декодера: смена хеша не запускает второй декодер на том же таймлайне.
- Ограничение очереди записи PCM приостанавливает stdout FFmpeg; остановка приложения отменяет незавершённые загрузки до закрытия зависимых сервисов.

Офлайн-тесты WAV/WebM удерживают вторую половину файла до получения первого PCM и сравнивают начальные отсчёты с обычным полным декодированием. Проверены общий transfer и ошибка оборванного потока.

Реальный сетевой прогон в отдельном профиле: первые PCM за 4,102 с, до появления проверенного готового файла. Это один замер, не гарантия задержки и не оценка звучания на слух.

### Реверберация

В «Звуке» добавлено небольшое стереопространство, 0–35%, по умолчанию выключено. Четыре затухающих фильтра на канал, сглаженная регулировка. Цепь: DJ-микс → реверберация → эквалайзер/моно/баланс → громкость → true-peak limiter. После ограничителя усиления нет.

Проверены точный bypass, спад хвоста и устойчивость на 22,05/48/96 кГц. Интеграционный тест через MixerCore использует перегруженный стереосигнал, реверберацию 35%, бас +12 дБ и предусиление +6 дБ без автоматического запаса: true peak ≤ −0,95 дБ; моно и баланс действуют и на хвост эффекта. Это не обещание отсутствия слышимых артефактов на любой музыке: ограничитель при такой перегрузке неизбежно уменьшает уровень.

Установщик: `apps/desktop/dist/MORA-Setup-0.2.0.exe`, 168 417 108 байт на момент сборки. Установленная у пользователя версия автоматически не заменялась.

## Осталось

1. Независимые скорость и высота тона с сохранением тайминга переходов, вокальных дорожек, перемотки и текста. Обычная смена playbackRate эту задачу не решает. План: [playback-speed-pitch.md](playback-speed-pitch.md).
2. Прослушивание реальных переходов: плотный вокал, сильно разный BPM, только что найденные записи до анализа. Подготовить сравнения и дать пользователю оценить слышимые артефакты.
3. Вокальный компонент для обычной настольной установки без ручной настройки Python. Текущие тесты не подтверждают наличие модели в установщике.
4. Discord Rich Presence по явному включению, перевод текстов, расширенная проверка обновления существующего профиля и офлайна в настоящем окне Electron.
5. Более быстрый SoundCloud-поиск и ранний старт M4A/MP4, если появится обоснованный способ получить пригодный для последовательного чтения источник.

## Первичные источники

- [FFmpeg: pipe protocol](https://ffmpeg.org/ffmpeg-protocols.html#pipe) — потоковый ввод и особенности контейнеров, требующих seek.
- [yt-dlp: output template](https://github.com/yt-dlp/yt-dlp#output-template) — управление выходным файлом.
- [Julius O. Smith: Schroeder Reverberators](https://www.dsprelated.com/freebooks/pasp/Schroeder_Reverberators.html) — основа небольшого алгоритмического пространства. Реализация MORA собственная.
