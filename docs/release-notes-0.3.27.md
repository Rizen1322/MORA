# MORA 0.3.27 — радио и читаемый плеер

- Исправлено переключение с плейлиста на онлайн-радио: кнопка отражает текущую очередь, а старая радиосессия больше не может присоединиться к плейлисту во время запуска трека.
- Личные рекомендации больше не начинаются с обязательного блока любимых песен, использованных для поиска. Учитывается свежая история последних двух часов, источники и порядок кандидатов меняются между запусками.
- В режиме «Вперемешку» начало радио отдаёт больше места открытиям. Режим «Ближе к любимому» и явное радио по выбранному треку сохранены.
- Длинные названия в полном плеере получают меньший шрифт без обрезания текста.
- Включены свежие доработки планировщика v19.3: более плавный вход следующего трека под эхо и более продолжительный хвост. Кэш автоматических планов обновлён.

Windows x64. Установщик без цифровой подписи Authenticode.
