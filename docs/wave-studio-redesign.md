# «Моя волна»: персональная станция

Страница переработана в рамках существующей палитры «Хвойная ночь», Onest и Unbounded. Применён локальный skill `skill/taste-skill-main/skills/redesign-skill/SKILL.md`, прочитаны DESIGN (7).md, DESIGN (8).md и docs/design-notes.md. Названные пользователем наборы core-3d-animation и другие не найдены в локальной папке skill; их установка не выполнялась.

## Изменения

- Вместо панели с крупным заголовком и набора равнозначных карточек — композиция персональной станции: типографика слева, живая объёмная скульптура справа.
- Three.js загружается динамически. 72 нити образуют деформируемое тороидальное тело, GLSL изменяет форму и свет. Реальный спектр существующего analyser влияет на движение; граф аудио не менялся.
- Небольшой параллакс курсора, мягкое появление разделов, состояния hover/pressed/focus.
- Источник отделён от действия воспроизведения: коллекция / Яндекс. Подключённый Яндекс можно запускать без локальных треков. Пока источник не запущен, переключение не меняет текущую музыку.
- Три настройки в одном блоке: энергия, характер, подбор для сведения. Переключатель «Для микса» меняет существующий wave.mode, а не включение самого движка AutoMix.
- Текущий трек, реакции и очередь сохранены. Подробное объяснение рекомендаций свёрнуто в details. Пустые состояния и сообщения об ошибках оформлены явно.

## Доступность и ресурсы

При prefers-reduced-motion WebGL не создаётся, остаётся статичная CSS-композиция. То же при отсутствии WebGL или ошибке загрузки чанка. Рендер приостанавливается вне viewport и при document.hidden; ресурсы, наблюдатели и обработчики освобождаются при unmount. DPR ограничен 1.5. Контекст WebGL обрабатывает потерю/восстановление.

Кнопки используют aria-pressed, переключатель — role=switch; настройки сгруппированы fieldset/legend. Есть видимый keyboard focus, disabled/loading и подписи.

## Проверки

- `npx tsc -p apps/web --noEmit` — успешно.
- `npm run build` — успешно. Three.js выделен в отдельный динамический чанк (~130 kB gzip).
- В живом приложении localhost:4730/#/wave подтверждены WebGL-canvas, отсутствие предупреждений/ошибок консоли, переключение энергии с восстановлением исходного значения, resume/pause с возвратом в паузу.
- Проверены viewport 390×844, 789 px и 1440×1000: document.scrollWidth равен ширине viewport; переполненных кнопок сегментов не найдено.
- Скриншоты: docs/screenshots/wave-studio/.

Реальное устройство с медленным GPU и системный reduced-motion в браузере отдельно не тестировались. Яндекс-запуск, skip и реакции сохранены на существующих controller/react обработчиках; аккаунтные реакции при визуальной проверке не изменялись. Аудиодвижок/планировщик/сервер не редактировались.

Three.js API: https://threejs.org/docs/
