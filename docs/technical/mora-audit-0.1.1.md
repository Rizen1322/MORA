# MORA 0.1.1 — проверка и исправления, 21 октября 2026

## Что исправлено

- Обложки импортированных записей: сохраняется URL кандидата при импорте. Если у существующего трека отсутствует локальная картинка, `/api/tracks/:id/cover` восстанавливает её по данным источника. Параллельные запросы используют одну загрузку; неудачные запросы временно кешируются. Обложка плейлиста также может использовать этот путь. Аудио для восстановления картинки не скачивается.
- Загрузка изображения ограничена по размеру, типу и разрешённым CDN; произвольные адреса не проксируются.
- yt-dlp: явная UTF-8 кодировка исправляет искажённые пути в папках с кириллицей. Поток stdout собирается без повреждения символов на границах чанков; прогресс обрабатывается отдельно от JSON.
- Отмена общей подготовки: уход фонового потребителя больше не отменяет загрузку для активного слушателя. Работа останавливается после ухода последнего потребителя.
- Очередь загрузок при остановке сервера прекращает запуск задач, сохраняет незавершённые задачи и ждёт завершения активных обработчиков перед закрытием базы.
- Радио: устаревшие ответы не дописывают треки в новую сессию. Идентификаторы разных источников не смешиваются. Фильтр исполнителей больше не возвращает отложенные треки в конец пачки в обход ограничения.
- Предпрослушивание версии: запоздалый ответ после закрытия панели или смены прослушивания не останавливает новый трек.
- Тексты: отменяются устаревшие ответы; смена привязанной записи перезагружает текст.
- Ошибки подготовки отображаются в поиске с возможностью закрыть сообщение.

## Плейлисты

В настройках доступны сохранение JSON и восстановление с предварительным подтверждением. Отдельный плейлист экспортируется с его страницы.

Копия содержит названия, порядок, повторы и идентификаторы источников. Не содержит аудиофайлов, токенов, истории и абсолютных путей. Восстановление создаёт отдельные списки; повторное восстановление того же набора обновляет его копии. Локальные отсутствующие файлы остаются на своих местах как недоступные записи. Валидация выполняется до записи; восстановление проходит в транзакции. Лайки, настройки звука и привязки альтернативных версий в этот формат не включены.
