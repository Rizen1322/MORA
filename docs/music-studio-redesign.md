# Music Studio: главная, коллекции и плеер

20 октября 2026. Визуальное продолжение «Моей волны» в существующем React/CSS приложении. Палитра «Хвойная ночь», Onest/Unbounded, нефрит для действий и янтарный для AutoMix сохранены.

## Дизайн и движение

- Главная: крупная персональная витрина с живой Three.js-скульптурой, блок текущего прослушивания, прямые ссылки в медиатеку/любимое/плейлисты, более выразительные обложки и ритм разделов.
- Медиатека: новый заголовок, пространственная композиция обложки и винила, вкладки треков/альбомов/исполнителей/плейлистов. Расширенные фильтры свёрнуты в details. Поиск, сортировка и списки сохранены.
- Любимое: собственная объёмная обложка с сердцем; поиск по названию/артисту, длительность подборки; дизлайки раскрываются отдельно.
- Плейлисты: отдельная полка с созданием и ссылками на подборки; новая обложка страницы, поиск, skeleton/loading/error-retry. Действия в отфильтрованном списке используют entryId именно видимой строки. Нет запуска пустого результата; добавлена защита от запоздавшего ответа другого плейлиста и восстановление данных при ошибке сохранения порядка.
- Desktop-плеер: плавающая панель с ограничением ширины 1960 px; крупные элементы управления, превью следующего трека, отдельная читаемая строка AutoMix под таймлайном, янтарная граница активного сведения.
- Mobile-плеер: более крупная плавающая панель, читаемая обложка, контрастная кнопка воспроизведения, индикатор загрузки.

Three.js используется только в hero главной через существующий WaveSculpture. Обложки и винил коллекций — CSS 3D, без дополнительных WebGL-контекстов. Есть пружинящие hover/pressed состояния, появление элементов и прогрессивное scroll-driven появление секций при поддержке view timeline. Reduced motion отключает анимации; WebGL освобождает ресурсы и контекст при уходе со страницы, приостанавливается вне экрана/скрытой вкладки.

Применены локальные skills: skill/taste-skill-main/skills/redesign-skill/SKILL.md и skills/soft-skill/SKILL.md из того же набора. Использованы docs/design-notes.md и ранее прочитанные DESIGN (7).md / DESIGN (8).md. Перечисленные пользователем дополнительные наборы core-3d-animation и др. в локальном каталоге не найдены; не устанавливались. GSAP/R3F/Babylon и другие дублирующие движки не добавлялись.

## Проверки

- `npx tsc -p apps/web --noEmit` и `npm run build`: успешно.
- `npx vitest run apps/web/test --maxWorkers=2`: 71/71.
- Живой localhost:4730: главная, медиатека, любимое, пустая полка плейлистов; поиск Bleeder/Money даёт одну строку; создание плейлиста открывает доступную с клавиатуры форму (отменена без записи в пользовательскую базу).
- Play/Pause из нового desktop-плеера, строка AutoMix, открытие/закрытие очереди из превью следующего трека проверены. После проверки воспроизведение оставлено на паузе.
- Отдельный сервер localhost:4731 на временной базе `tools/.cache/ui-studio-fixture-*` проверял страницу реального плейлиста: фильтр, disabled play при пустом результате, удаление именно найденного трека, порядок и сохранение нового названия. Пользовательские плейлисты и реакции при этих тестах не менялись. Временный сервер остановлен; сценарий tools/.cache/ui-studio-preview.ts.
- Визуальные проверки на 390×844, 789 px, 1440×1000; широкий плеер проверен на 2560 px (ширина панели 1960 px). Проверенные страницы не создают горизонтального переполнения документа. Ошибок консоли в проверенном браузерном сценарии нет.
- Высота виртуализированных строк TrackList не менялась: сохранена совместимость с ROW_H=56.
