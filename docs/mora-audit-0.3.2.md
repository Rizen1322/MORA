# MORA 0.3.2 — проверка ПК

21 октября 2026. iOS отложен по последнему указанию пользователя. Эта итерация — desktop/web и общий AutoMix DSP.

## Готово

- Онлайн-радио сохраняет сессию при удалении, перестановке и очистке будущих треков. Новая очередь прослушивания отличается от её редактирования через queueVersion. Если резерв закончился, плеер ждёт пополнения и продолжает с нового трека, не перезапускает закончившийся и не обращается к API другого источника.
- Локальная/Яндекс-волна также пополняется после редактирования очереди. Удалённые кандидаты не восстанавливаются принудительно.
- Заголовок полноэкранного плеера центрируется относительно окна, включая симметричный резерв под Windows caption buttons. Следующий трек меняется через существующую CSS-анимацию появления/ухода.
- Оба визуализатора используют общие RMS/частотные огибающие, повторные низкочастотные атаки и небольшую историю с поправкой на задержку выхода. Для задержки используется [AudioContext.getOutputTimestamp](https://developer.mozilla.org/en-US/docs/Web/API/AudioContext/getOutputTimestamp), при отсутствии — base/outputLatency. Это оценка, Bluetooth и фактическую синхронность надо оценивать на конкретном устройстве.
- Спектральные участки скульптуры интерполируются по замкнутому кругу, без скачка на границе 0/15. Фоновая геометрия не ускоряется от энергии вместо реакции на неё.
- Скрытая полноэкранным плеером скульптура не рендерится. Palette CSS читается 2 раза в секунду, история визуальных данных ~11 KB, обложечные GPU-текстуры ограничены шестью с защитой активной пары и освобождением ресурсов. Фон затемнён для читаемости ярких обложек.
- «Собрать микс» в плейлисте, два режима, preview/копия/прослушивание. Worker; измеренные метаданные, сохранение повторов, исходный плейлист не меняется.
- Обнаруженное при визуальной проверке обрезание модального окна нижней панелью устранено: portal в body и ограничение высоты с прокруткой.
- Настоящий HPF/LPF фильтр деки и ограничение кэша — подробности в соседних отчётах.

## Ограничения и продолжение

Полная переработка всех 24 идей внешнего ИИ не заявляется выполненной. Состояние каждого предложения и порядок продолжения на ПК — в `automix-ai-review.md`. Объективные уровни и тесты не доказывают отсутствие любого слышимого артефакта. Причина ранее нерегулярного хрипа не установлена воспроизведением в этой итерации.

Исходники и localhost:4730 обновлены. Установленная MORA также обновлена с 0.3.1 до **0.3.2**, установщик завершился с кодом 0; запуск нового backend подтверждён журналом. Перед обновлением через SQLite backup сохранена согласованная копия базы в `tools/.cache/pre-update-0.3.2/automix.sqlite`. После обновления все 238 исходных ID треков на месте, `PRAGMA quick_check` — ok. Установщик 480 304 717 B включает CPU runtime и модель вокала, но не пользовательскую музыку; SHA-256 в `release-0.3.2.json`.

Новые квоты проверены и на установленном профиле: генерируемый кэш уменьшился **9,35 → 1,46 GB**, исходные remote-файлы сохранили количество и суммарный размер (226 / 752 005 285 B). Свободное место C после этой очистки — около **42,4 GB**.
