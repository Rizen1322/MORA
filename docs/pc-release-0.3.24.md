# MORA 0.3.24 — Windows

1 ноября 2026. Исправлены гонки быстрых Next/Previous в Rust desktop-движке и общем контроллере.

Когда движок уже начинал переход, повторный запрос мог изменить ожидаемый ID плана. Движок игнорировал arm во время активного перехода, а контроллер терял события исходного плана. Контроллер теперь сохраняет отправленные планы конкретной подготовленной пары и принимает подтверждённый движком план по start/swap/end либо активной телеметрии. Асинхронный быстрый skip проверяет исходный план, намерение пользователя и поколение воспроизведения после получения PCM.

Seek теперь гасит противоположную деку и при уже завершённом переходе. Ранее при устаревшем состоянии контроллер мог снова запустить старую деку, оставив новую звучать без ограничения времени. Изменение синхронно внесено в Rust и TS-референс.

Проверки независимого агента gpt-6-astra (low): пять регрессий контроллера, две проверки TS-микшера и Rust integration-тест обоих направлений seek. Всего 1160 тестов в 150 файлах, общий TypeScript и 11 Rust-тестов прошли.

Упакованное приложение проверено на Electron 44.9.2/Rust/WASAPI в отдельном профиле с нулевой громкостью: четыре серии по четыре Next с интервалом 35 мс, две серии отменены Previous. После каждой проверено соответствие названия активной деке и единственная играющая дека; финальный Next также сработал. Pause/Resume, смена устройства и восстановление после завершения дочернего аудиопроцесса прошли. PCM underruns: 0; device underruns: 0; slow blocks: 0; максимальный интервальный p99 DSP: 0,0447 мс. Отчёт: data-bench-results/rust-audio/desktop-smoke-packaged.json.

Проверка упакованного backend без системных Node/Python/FFmpeg на PATH прошла: поиск, каталог, warmup, загрузка, обложка, подготовка и PCM 65536 байт. Отчёт: data-bench-results/release-0.3.24/backend/report.json, ok=true. Личный профиль не использовался.

Установщик MORA-Setup-0.3.24.exe: 169927734 байта. SHA-256: bd4baba99dcd76fac2322fd33abd8cc9d760a3ce30dd606c38d55b068f30499e. verify-release проверил app.asar, версию, updater, latest.yml, blockmap, SHA-512, Rust-бинарник и лицензии. Цифровой подписи Authenticode нет.

Проверки выполнялись без прослушивания длительной онлайн-радиосессии. Сетевое ожидание загрузки всё ещё может приводить к штатному резервному кроссфейду; исправлена потеря состояния при гонках управления.
