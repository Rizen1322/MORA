# MORA 0.4.19

Windows x64, Tauri.

- AutoMix подбирает длинное сведение или короткий подхват на границах музыкальных фраз. Бас передаётся постепенно, а скорость второго трека возвращается к исходной после ухода первого.
- Для размеченных инструментальных записей доступен трёхдольный мост в другой темп. Входящий трек начинает звучать до смены, а петля уходит под его первую долю.
- Локально одобренный трёхдольный переход можно сохранить для точной пары записей. Настройки и исходные записи должны совпадать с одобренным вариантом.
- Новые варианты работают на полном миксе. Перед автовыбором Windows-версия проверяет рендер на уже доступном аудио. При неподходящих парах или отсутствии готового аудио используется базовый план.
- Для синхронизации дизлайков Windows-плеер запрашивает только нужные треки. Сохраняются реакции Яндекс Музыки, которые переопределяют локальные.
