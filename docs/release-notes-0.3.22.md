MORA 0.3.22 — улучшения AutoMix

- Добавлена поддержка локальных оценённых переходов: сохранённый вариант применяется только к тем же аудиозаписям, направлению пары и совместимым настройкам.
- Новый дизлайк отменяет дальнейшее применение конкретного сохранённого варианта. При изменении записи или настроек используется обычный AutoMix.
- Исправлена перепроверка рисунка ударных после сдвига точки входа и пересчёт прихода энергии.
- Усилена защита от ухудшения конфликтов и потери материала при выборе альтернативного сведения.
- Исправлена диагностика переходов с петлями: неподдерживаемые измерения больше не выдаются за фактически звучащий материал.

Разделение вокала и нейросетевые модели не включены. Экспериментальный редактор остаётся скрыт; новые петлевые рецепты не распространяются автоматически на все треки.

Windows x64. Установщик сохраняет медиатеку и настройки.
