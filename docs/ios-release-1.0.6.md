# MORA iOS 1.0.6 (build 7), 24.10.2026

В режиме «Минимум движения» круг на главной и странице «Моя волна» заменён статичной композицией из тонких мятных линий. Рисунок — SVG без цикла анимации и чтения аудиоспектра. В полноэкранном плеере остаётся фон в цветах обложки без создания Canvas/WebGL-рендерера. Режим также применяется через системную настройку уменьшения движения и существующий режим энергосбережения iOS.

Настройка: Оформление → Анимации → Минимум движения. Проверены внешний вид на широком и узком экране и переключение в полные анимации. Реальный iPhone и расход батареи требуют проверки на устройстве.

Исходники и iOS workflow находятся в ветке `ios`. ZIP `MORA-ios-mac-1.0.6.zip` содержит проект, готовые веб-ресурсы, BUILD-IPA.command и манифест SHA-256. Команда сборки на Mac с Xcode 26+ и Node 22.13+: `sh BUILD-IPA.command`.

Готовая `MORA-1.0.6-unsigned.ipa` требует подписи через Sideloadly/AltStore. Для обновления сохраняйте Bundle ID `ru.mora.player` и аккаунт подписи.
