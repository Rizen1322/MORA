# MORA iOS 1.0.5 (build 6), 24.10.2026

- Next/Previous и перемотка с экрана блокировки передаются через нативный MPRemoteCommandCenter в существующий плеер. WebKit сохраняет метаданные, обложки и часы. Перемотка включается после получения длительности трека; двойная обработка навигации исключена.
- После ошибки записи или переименования файла медиатека остаётся dirty и повторяет сохранение без новых изменений. Первые три повтора выполняются через 5 секунд, дальнейшие — через минуту. Раннее сохранение при уходе в фон также получает короткий retry.
- После открытия sql.js освобождается исходный образ БД, а повторное открытие без свежего образа отклоняется, чтобы не затереть медиатеку пустой базой.
- Добавлена сборка unsigned IPA в GitHub Actions: macOS 15, Xcode 26.2, Node 24.

Проверены типы всех частей проекта, **956 тестов в 122 файлах**, production-сборка мобильных веб-ресурсов. Нативная сборка выполняется workflow `iOS unsigned IPA`. Эти проверки не заменяют проверку системных кнопок, Bluetooth и фоновой работы на физическом iPhone.

ZIP `MORA-ios-mac-1.0.5.zip` содержит проект с веб-ресурсами и командой `BUILD-IPA.command`. На Mac с Xcode 26+ и Node 22.13+:

```sh
sh BUILD-IPA.command
```

Выход: `apps/mobile/MORA-unsigned.ipa`. Готовую unsigned IPA нужно подписать при установке через Sideloadly/AltStore. Для обновления поверх текущей версии сохраняйте Bundle ID `ru.mora.player` и аккаунт подписи.

Релиз iOS имеет отдельный тег `ios-v1.0.5`; Windows остаётся на `v0.3.17`.
