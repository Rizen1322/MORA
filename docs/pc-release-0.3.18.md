# MORA 0.3.18 для Windows x64

24 октября 2026. Новая Windows-сборка актуальной кодовой базы main после выпуска iOS 1.0.5. Desktop-пакет и package-lock согласованы на версии 0.3.18.

Установщик: `MORA-Setup-0.3.18.exe`, 168950706 байт (около 169 МБ). AutoMix использует полный микс; локальный вокальный runtime в пакете отсутствует.

Проверки:

- 25 desktop-тестов в 8 файлах прошли. Полный набор этой кодовой базы (956 тестов в 122 файлах) и типы всех частей прошли при подготовке iOS 1.0.5; в Windows-выпуске изменены версия и документация.
- Production-сборка desktop, NSIS-установщик, blockmap и verify-release прошли. Версия внутри app.asar, версия electron-updater, GitHub feed, имя/размер/SHA-512 установщика в latest.yml согласованы.
- Встроенный сервер из ресурсов упакованного приложения запущен в Electron 44.9.2 с отдельным профилем и PATH без системных Node/Python/FFmpeg. Проверены старт, отсутствие вокальной модели, поиск YouTube Music/SoundCloud, страницы исполнителя и альбома, warmup без изменения медиатеки, подготовка трека, PCM (65536 байт), обложка и корректный выход.

SHA-256 установщика: `54f4d09f9f50a0bcab8fa7d09fd9c07a74cfa5cefd8bd73393143b84825bf494`.

Установщик не подписан сертификатом Windows. Установка поверх пользовательской копии и слуховая проверка данным выпуском не выполнялись. Профиль пользователя не изменялся.

Релиз: [v0.3.18](https://github.com/Rizen1322/MORA/releases/tag/v0.3.18). Для 0.3.14+ доступно обновление через настройки; более ранние версии обновляются установщиком вручную. [Поведение автообновления](desktop-auto-update.md).
