# MORA 0.4.22

Windows x64, Tauri.

- Полноэкранный плеер разворачивается из текущей обложки и сворачивается обратно. MORA учитывает настройку Windows «Эффекты анимации», а боковые панели плавно освобождают место в окне.
- Если Яндекс Музыка подключена, общий поиск открывается с неё. Список остаётся на месте, пока загружаются новые результаты. По результатам можно перемещаться клавиатурой, а страницы артистов и альбомов открываются из кеша при возврате.
- При потере сети «Волна» продолжает подбор из доступной музыки на устройстве и возвращается к онлайн-рекомендациям после восстановления связи.
- Плеер начинает воспроизведение с меньшим начальным буфером. Главная и настройки больше не обновляются на каждом тике, а визуализатор не получает поток waveform, пока окно скрыто.
- Треки можно запустить из истории. Ползунки звука теперь показывают фактическое положение, а окно «Другая версия» доступно поверх полноэкранного плеера.
- Тёмный фон виден с первого кадра. При аварийном завершении оболочки Windows закрывает её фоновые процессы.
