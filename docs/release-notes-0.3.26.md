# MORA 0.3.26 — подключение нового планировщика

- Доработано подключение планировщика v19.2 к настольному плееру. После перемотки за точку сведения переход пересчитывается с текущего места; готовый музыкальный план заменяет резервный кроссфейд ближе к его началу.
- Автоматический переход после перемотки сохраняет музыкальное сведение, даже если кнопка «Следующий» настроена на мгновенное переключение. Сама настройка не меняется.
- Обновлён ключ кэша автоматических планов: старые варианты пересчитываются. ID сохранённых одобренных планов сохранены.
- Учтено время подготовки: пересчитанный кроссфейд получает запас для передачи в аудиодвижок.

Windows x64. Установщик без цифровой подписи Authenticode.
