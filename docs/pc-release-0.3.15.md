# Проверка MORA 0.3.15

23 октября 2026 года. Небольшое исправление обновлятора поверх опубликованной 0.3.14. Незавершённые изменения AutoMix из основной рабочей папки не переносились.

- Повторная команда загрузки возвращает результат уже начатой операции. После отмены она не возобновляет загрузку автоматически.
- Регрессионная проверка: два нажатия «Скачать», отмена, позднее событие завершения и затем явная повторная загрузка с новым токеном.
- Проверка типов core/server/web/desktop прошла; **837/837 тестов**, 95 файлов.
- В основной рабочей папке также отдельно прошли 7 тестов обновлятора.
- Упакованное приложение запущено с отдельным пустым профилем: IPC возвращает currentVersion 0.3.15, панель обновлений открывается без горизонтального переполнения.

Сертификата Windows нет. Замена установленной пользовательской копии и сбой питания во время установки не проверялись. Личные профили не менялись. Проблема задержки YouTube у друга в этот выпуск не входит.

С 0.3.13 требуется одна ручная установка последней версии; с 0.3.14 доступно обновление из настроек. [Поведение и публикация](desktop-auto-update.md).
