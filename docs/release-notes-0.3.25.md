# MORA 0.3.25 — фоновый плеер и упрощённое управление

- Воспроизведение и подготовка очереди работают в основном процессе приложения с Rust/WASAPI. Закрытие окна в трей и приостановка страницы не останавливают переданную очередь.
- PCM читается движком из локального кэша, без передачи аудиоблоков через интерфейс в JSON/base64. Ближайшие записи подготавливаются заранее.
- Исправлены изменения громкости при фоновой переподготовке перехода: уровень текущего трека сохраняется до его окончания, если пользователь сам не меняет нормализацию.
- Новый планировщик: передача через фильтр, смена несовместимых ритмов на сильной доле и обновлённые DJ-приёмы. Используются оригинальные записи, без вырезания вокала.
- Windows показывает обложку, название и позицию в системной медиапанели; работают системные кнопки и перемотка.
- Подготовка плейлиста для офлайна: загрузка, анализ, расчёт переходов, прогресс и отмена. Добавлены отмена правки очереди, статусы готовности и управление местом на диске.
- Панель плейлиста и меню треков стали компактнее; редкие функции сгруппированы. Второстепенные кнопки полного плеера перенесены в «Ещё», постоянная подсказка о кнопке «Следующий» удалена.
- Исправлено восстановление обложек Яндекс Музыки после неудачной загрузки и при пустой обложке альбома.
- Последние переходы и быстрые переключения записываются в диагностику также при скрытом окне.

Windows x64. Установщик без цифровой подписи Authenticode.
